# Клавобой

Тренажёр слепой печати в виде ретро-игры: погоня, арена, гонка и буквопад. Есть игра вдвоём онлайн и по очереди, а камера может следить, не смотришь ли ты на клавиатуру.

Вся игра — один файл `index.html`. Онлайн-дуэль работает через Firebase Realtime Database: правила доступа лежат в `database.rules.json`.
